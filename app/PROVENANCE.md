# Provenance

Where this repo's initial commit came from, and why. PreCut was built
across many Claude chat sessions without a git repo. Several partial
copies existed on disk in different states. This file records what was
chosen, what was rejected, and what is known to be missing, so nobody has
to redo the archaeology.

Established 31 August 2026.

## What the initial commit is

`~/Downloads/precut_beta1_package.zip`, contents dated 25 April to
1 May 2026, minus `__pycache__` and `.DS_Store`.

Despite the `beta1` filename, `src-tauri/tauri.conf.json`,
`src-tauri/Cargo.toml`, and `README.md` all declare **1.0.0-beta.3**.
The filename is stale. This is the newest complete source that exists.

## The installed app diverges from this repo

`/Applications/PreCut.app` is **not** what this repo builds. Two known
differences:

1. **It has plugin code this repo does not.** `premiere_exporter.py` and
   a `handle_export_to_premiere` handler were hand-patched into the app
   bundle on 29 June 2026 for an abandoned Premiere CEP panel. That work
   is deliberately excluded here. See DECISIONS.md.

2. **It is missing beta.2 and beta.3 fixes this repo has:**
   - `auto_include.py` support for `.svg`, `.bmp`, `.gif`, `.webp`
   - `_UNSUPPORTED_REASONS`, giving real error messages for files
     Premiere cannot import via XML (`.cube` LUTs, `.psd`, `.ai`, docs)
     instead of dropping them silently
   - warning pass-through in `multi_exporter.py` so those messages reach
     the log panel
   - a non-admin-account pre-check before the Homebrew install, added
     after a beta tester on a non-admin account got a bare "FAILED"

On 30 July 2026 someone copied files from the old v2 backup over the
installed app, which **reverted** the admin-account fix. The app's
`setup_helper.py` is byte-identical to the v2 backup's.

**Consequence:** the running app behaves like an older build. Rebuilding
from this repo produces a newer app that has never been run. Expect small
differences and test before trusting it.

## Verification performed before committing

Against `~/precut-venv-fresh/bin/python` (3.11.15):

- All 35 backend modules compile and import cleanly.
- `backend.py` starts, emits its `ready` event, responds to
  `list_projects` with the two real projects on this machine, and shuts
  down cleanly on `shutdown`.
- No plugin, CEP, UXP, or ExtendScript code is present.

**The Tauri build was verified on 31 August 2026.** `npm install` plus
`./scripts/build_dmg.sh` completed clean on the first attempt, producing
`dist-release/PreCut-1.0.0-beta.3-arm64.zip` (6.2 MB, ad-hoc signed,
archive round-trips with a valid signature). The built app reports
`1.0.0-beta.3`, contains the beta.3 auto-include fixes, and carries no
plugin code.

## Current shipping build

**1.0.0-beta.3 is the real build as of 31 August 2026.** It was built
from this repo, imported into Premiere Pro against a real project, and
confirmed by Ryan to import everything correctly. It now occupies
`/Applications/PreCut.app`, replacing the April 1.0.0-beta.1 build that
had been running for four months.

Tagged `v1.0.0-beta.3`.

The previous beta.1 build is preserved at
`~/Desktop/PreCut/BackupPreCut_v3(1.0.0-beta.1 pre-beta3).zip`, verified
to extract to a working app. Database migrations are additive-only, so
rolling back to it stays possible.

This closes the split described above: the installed app and this repo
are now the same code.

## Known gaps

- ~~No lockfiles.~~ **Resolved 31 Aug 2026.** Both `package-lock.json`
  and `src-tauri/Cargo.lock` were generated by the first successful build
  and are now committed, pinning the dependency graph.
- **No test suite.** There are no tests anywhere in the codebase.
- **`src-tauri/icons/icon.icns` is not present.** `tauri.conf.json`
  references it; `scripts/make_icns_from_icon.py` generates it.
- **Frontend source after 1 May 2026 may not exist.** The installed
  binary was rebuilt 30 July, but Tauri compresses embedded assets so
  JSX cannot be recovered from it. Evidence suggests that rebuild was a
  reinstall of older files rather than new work, but if UI changes were
  made after 1 May, that source is lost.
- **Naming is inconsistent.** `package.json` and `Cargo.toml` still call
  the package `broll-buddy-app`; the bundle identifier is
  `com.brollbuddy.precut`; the backend version string is
  `0.4.43-precut-logo-cleanup`; several module docstrings still say
  "B-Roll Buddy". Renaming touches the app identifier and would orphan
  `~/Library/Application Support/PreCut`, so it was left alone.
- **`~/.broll_buddy/`** still holds the pre-rename SQLite index, extracted
  frames, and LanceDB vectors, last written April 2026.
